# openai-flash-cart

GBDK-2020 Game Boy project.

The starter ROM displays:

`	ext
Vibe GB
by ModRetro
`

Use this as a clean prompt-ready cartridge screen, then replace src\main.c as the game takes shape.

Build:

``powershell
.\openai-flash-cart\game\build.ps1
``

Run:

``powershell
.\openai-flash-cart\game\run.ps1
``

Output:

``text
outputs\openai-flash-cart.gb
``
